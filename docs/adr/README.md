# Architecture Decision Records

Registros imutáveis de decisões significativas e do seu rationale. Formato:
[template ADR de Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
Uma decisão é alterada adicionando um ADR que a substitui, nunca editando um ADR já
aceito ([ADR-0001](0001-registrar-decisoes-de-arquitetura.md)).
